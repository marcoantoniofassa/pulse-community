# Segurança

Reporte vulnerabilidades em privado: https://github.com/marcoantoniofassa/pulse-community/security/advisories/new

Não abra issue pública com tokens, transcrições, dados pessoais ou passos que exponham terceiros. Envie descrição mínima com dados fictícios e versão afetada. Não há prazo de resposta garantido; o projeto é mantido pela comunidade.

Correções são distribuídas em novas releases. Use a versão comunitária mais recente. O pacote atual não é notarizado pela Apple; confira a origem oficial e as limitações no guia.
