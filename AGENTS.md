# Pulse comunidade
Swift 6.2+, SDK macOS 26+, Apple Silicon. Sem dependências de runtime externas.
`bash build.sh` gera dist/Pulse.app sem instalar; `bash release.sh` empacota o DMG.
Verifique com `python3 tests/check_distribution.py`, `swift build -c release` e inspeção do pacote.
Não leia dados pessoais, use texto sintético. Não registre transcrição, clipboard ou apps ativos em logs.
Preserve a identidade com.marcofassa.pulse e os dados em Application Support/Pulse.
Não execute o app em desenvolvimento sobre a instalação pessoal para testes de permissões.
